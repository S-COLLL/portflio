# Shreya Konduskar · Portfolio

A single-page portfolio website built with **HTML, CSS and React**. No build tools or `npm install` needed.

Live site: https://s-colll.github.io/portflio/

## Files

```
index.html    The page: loads the fonts, style.css, React and app.jsx
style.css     All styling: colours, layout, animations, dark mode
app.jsx       The React app: content, components and pages
images/       Photos and certificates
```

To change the site's text, edit the content section at the top of `app.jsx`.

## Run it locally

Open the folder in VS Code, right-click `index.html` and choose **Open with Live Server**.
(Double-clicking `index.html` shows a blank page, because browsers don't load `app.jsx` straight from a folder.)

## Deploy

GitHub Pages serves the `main` branch as it is, so every push updates the live site.
